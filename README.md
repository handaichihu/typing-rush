# ⚡ 打字闪电 Typing Rush

一个纯 HTML/CSS/JavaScript 实现的打字练习小游戏，零依赖，双击 `index.html` 即可在浏览器中游玩。

## 玩法

1. 选择游戏时长（30 / 60 / 120 秒）和难度（简单 / 普通 / 程序员 / 困难）
2. 点击「开始游戏」，按照高亮提示输入出现的单词
3. 打完一个单词按 **空格** 自动跳到下一个单词
4. 在时间内拼出尽可能多的单词，冲击更高的 WPM！

## 特性

- 📊 实时统计：WPM（每分钟词数）、准确率、得分、剩余时间
- 🔥 连击系统：连续无错单词获得连击加分
- 🎯 四档难度：短单词 / 混合词汇 / 程序员词汇（默认） / 长单词+符号
- 💻 程序员词库：202 个常用编程词汇（变量、函数、async、git、docker、refactor…）
- 💡 单词释义：全部 360+ 个单词都配有中文释义，打字时实时显示，边打字边记单词
- ✅ 严格纠错：打错的字母标红，改正后才能通过
- 🏆 本地最高分记录（localStorage），跨局保留
- ⌨️ 支持随时按 回车 快速重开

## 在线体验

启用 GitHub Pages 后访问：
`https://<你的用户名>.github.io/typing-rush/`

（仓库 → Settings → Pages → Source 选择 `main` 分支根目录）

单文件 `index.html`，无任何框架和外部依赖。
